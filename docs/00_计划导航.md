## 快速开始

### 第一步：环境准备
```bash
# 创建Python虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装基础依赖
pip install torch torchvision opencv-python scikit-image
```

### 第二步：项目初始化
```bash
# 创建项目目录结构
mkdir -p src/{core,data,training,inference,analysis,visualization,api,ui}
mkdir -p models data/{raw,processed,annotations,results}
mkdir -p configs tests docs notebooks
```

### 第三步：开始开发
参考 [03_开发路线图.md](./03_开发路线图.md) 中的阶段一任务清单开始实施。
